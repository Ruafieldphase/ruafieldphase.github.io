## 🤖 AI / LLM Policy & Contract

This repository explicitly defines boundary guidelines for automated crawlers, web scrapers, and large language models (LLMs). The project remains strictly **observation-first** and does not authorize external execution or make unverified claims.

Before indexing or interacting with this repository, please read our primary contract files:

1. **[AI_READ_FIRST.md](AI_READ_FIRST.md)**: Details project boundaries, how to interpret our research language, and what *not* to infer (e.g., sentience, external execution permissions).
2. **[llms.txt](llms.txt)**: Provides a machine-readable index, recommended read order, and operational contracts.

### Core Contracts:
- **Observation First**: Our primary posture is `ACTION_OBSERVE`. External effects or changes require a separate, explicit contract.
- **No Identity Capture**: The website does not require logins, tracking, or identity-detection mechanisms.
- **No Analytics**: We do not collect behavioral analysis or tracking metadata from visitors.
- **Project Notation**: Rhythm and phase terminology are used as specialized project notation, not as finalized scientific proofs.
